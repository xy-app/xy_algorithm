# 网格矩阵生成 (GridGenerator)

根据左上角起始坐标、行列数量与步长间距，批量生成规则二维点阵坐标集合，适用于背包格子巡检、九宫格遍历与多目标矩阵点击。

## 权限要求
> 无要求

## 运行参数

* `start_point` (MixedType)：网格左上角首个起始原点坐标，格式为 `"x, y"`（如 `"100, 100"`）。
* `rows` (MixedType)：网格总行数（如 `3`）。
* `cols` (MixedType)：网格总列数（如 `3`）。
* `step` (MixedType)：水平与垂直间距步长，格式为 `"step_x, step_y"`（如 `"50, 50"`）。

## 输出
> 返回按行优先顺序排列的所有网格点坐标元组列表，形如 `[(x0, y0), (x1, y1), ...]`，类型为 `Tuple`。

## 示例
```json
{
  "start_point": "100, 100",
  "rows": 2,
  "cols": 2,
  "step": "50, 50"
}
// 输出: [(100, 100), (150, 100), (100, 150), (150, 150)]
```
