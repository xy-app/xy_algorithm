# 连接字符串列表 (JoinString)

使用指定的分隔符将元组或数组列表中的多项元素拼接组合为一整段文字。

## 权限要求
> 无要求

## 子流程
> 不支持

## 运行参数

* `array` (MixedType)：输入的元组数组、列表或可迭代对象。
* `delimiter` (MixedType)：连接分隔符，例如 `,`, `-`, `\n` 或空字符串。

## 输出
> 返回拼接完成后的完整文本，类型为 `string`。

## 示例
```json
{
  "array": ["A", "B", "C"],
  "delimiter": "-"
}
// 输出: "A-B-C"
```
