# 哈希摘要计算 (HashDigest)

计算文本数据的密码学安全哈希摘要，支持 MD5 与 SHA-256，常用于签名校验、数据指纹与防重复比对。

## 权限要求
> 无要求

## 运行参数

* `text` (MixedType)：待计算哈希摘要的目标原始输入字符串。
* `algorithm` (String)：哈希算法名称，可选：
  * `md5`：MD5 摘要算法（输出 32 位小写十六进制字符串）
  * `sha256`：SHA-256 安全哈希算法（输出 64 位小写十六进制字符串）

## 输出
> 返回计算得到的十六进制小写哈希字符串，类型为 `string`。

## 示例
```json
{
  "text": "123456",
  "algorithm": "md5"
}
// 输出: "e10adc3949ba59abbe56e057f20f883e"
```
