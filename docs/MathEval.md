# 数值统计与运算 (MathEval)

提供数值序列的统计汇总（求和、平均值、极值）与实用算术运算。

## 权限要求
> 无要求

## 子流程
> 不支持

## 运行参数

* `operation` (String)：运算指令，支持：
  * `sum`：计算数字序列总和
  * `avg` / `average`：计算平均值
  * `min`：计算最小值
  * `max`：计算最大值
  * `round`：四舍五入，参数指定保留小数位数
  * `abs`：取绝对值
  * `add` / `sub` / `mul` / `div`：四则运算（与参数值进行计算）
  * `pow`：幂次运算（按参数指定的乘方）
* `values` (MixedType)：待计算的数字集合，支持数字元组数组、JSON 数组或逗号分隔的数值字符串（如 `"10, 20, 30.5"`）。
* `param` (MixedType)：算术操作附加参数（如四舍五入小数位数或第二操作数）。

## 输出
> 返回计算后的数值，类型为浮点数 `real`。

## 示例
```json
{
  "operation": "avg",
  "values": [80, 90, 100],
  "param": 0
}
// 输出: 90.0
```
