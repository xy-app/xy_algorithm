# 生成随机坐标点 (RandomPoint)

基于中心基准坐标点与指定扰动半径，生成圆盘范围内的拟人化抖动随机坐标，有效模拟真人点击以防自动化行为封禁。

## 权限要求
> 无要求

## 运行参数

* `center` (MixedType)：中心基准坐标点，格式支持坐标元组 `(x, y)` 或逗号分隔字符串 `"x, y"`（如 `"100, 100"`）。
* `radius` (MixedType)：随机扰动抖动半径（像素数值，例如 `10`）。

## 输出
> 返回圆盘范围内的随机坐标点元组，形如 `(x, y)`，类型为 `Tuple`。

## 示例
```json
{
  "center": "100, 100",
  "radius": 15
}
// 输出: (108, 95)
```
