# 截取子字符串 (SubString)

按起始字符下标与指定长度安全截取文本中的某段文字，完整支持负数倒数索引与多字节 Unicode / Emoji 字符。

## 权限要求
> 无要求

## 子流程
> 不支持

## 运行参数

* `text` (MixedType)：待提取的原始输入文本。
* `start` (MixedType)：起始字符下标（0-based）。支持正数（从左往右第 0 位开始）或负数（从末尾倒数，如 `-2` 表示倒数第 2 个字符）。
* `length` (MixedType)：截取的字符长度。`-1` 表示截取至文本末尾。

## 输出
> 返回截取出的子字符串，类型为 `string`。

## 示例
```json
{
  "text": "你好世界XY",
  "start": 2,
  "length": 2
}
// 输出: "世界"
```
