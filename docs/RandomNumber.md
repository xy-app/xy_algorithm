# 生成随机数字 (RandomNumber)

在指定的区间范围内生成随机整数或高精度随机浮点数。

## 权限要求
> 无要求

## 子流程
> 不支持

## 运行参数

* `range` (MixedType)：随机数区间范围，格式支持：
  * `"1..100"` 或 `"1, 100"`：在 `[1, 100]` 范围内生成随机整数
  * `"0.0..1.0"`：在 `[0.0, 1.0]` 范围内生成随机浮点数

## 输出
> 返回生成的随机数值，类型为 `number`。

## 示例
```json
{
  "range": "1..100"
}
// 输出: 42
```
