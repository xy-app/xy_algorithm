# 访问数组元素 (AccessArray)

根据位置序号读取、修改或取出列表、元组或数据容器中的某一项数据，支持正向索引（从 0 开始）与反向索引（从 -1 开始表示末尾）。

## 权限要求
> 无要求

## 子流程
> 不支持

## 运行参数

* `value` (MixedType)：数组或容器对象引用，支持元组、列表、字符串、数据集合或 JSON 数组格式文本。
* `index` (MixedType)：目标元素的索引下标。`0` 表示第一个元素，`1` 表示第二个元素；`-1` 表示最后一个元素，`-2` 表示倒数第二个元素。

## 输出
> 返回数组或容器中对应索引位置的元素对象，类型为 `Mixed`。

## 注意事项
* 当索引下标超出容器实际范围或传入非容器对象时，动作将记录错误日志并中断失败。
